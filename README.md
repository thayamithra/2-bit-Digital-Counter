# 2-Bit Digital Counter

## About the Project
This project was undertaken as part of ELECTROX'26, a college hackathon, to explore the design of a 2-bit digital counter using a 555 timer and digital logic ICs.

## Objectives
- Generate a clock signal using a 555 timer IC.
- Explore counter logic using NAND and NOT gates.
- Understand binary counting and sequential logic.
- Explore the planned integration of a seven-segment display.

## Components Used
- 555 timer IC
- NAND gate ICs
- NOT gate ICs
- Resistors and capacitors
- LED
- Breadboard and jumper wires

## Intended Counting Sequence
`00 → 01 → 10 → 11 → 00`

## Implementation and Results
The clock circuit was successfully constructed, and a 1-bit counter was demonstrated during the hackathon. The complete 2-bit counter and integrated seven-segment display were not demonstrated.

## What I Learned
- Practical circuit assembly and IC connections
- Clock generation using a 555 timer
- Basic digital logic and binary counting
- Hardware testing and troubleshooting
- Teamwork and problem-solving
